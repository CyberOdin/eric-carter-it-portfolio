# Eric P. Carter IT Portfolio

A lightweight static portfolio site built with plain HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Sign in to Vercel.
2. Create a new project or use the Vercel CLI.
3. Upload/import this folder.
4. No build command is required because this is a static site.

## Before publishing
- Verify every technical claim is accurate and can be explained in an interview.
- Replace or expand project details only after completing the corresponding lab task.
- Confirm that the resume button downloads the current resume.
- Add a GitHub button after confirming the correct GitHub profile or repository URL.
- Obtain permission before publishing a named recommendation.

## Files
- `index.html`: page content
- `styles.css`: visual styling and responsive layout
- `script.js`: mobile navigation and footer year
- `Eric_Carter_Healthcare_IT_Resume.docx`: downloadable resume
Deployment test: GitHub to Vercel connection verified.
